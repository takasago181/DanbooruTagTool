# Data roles after Foundation

Production authority is `authority/catalog/current/manifest.json`. Maintenance
compiles it into a fresh output `catalog.db`; WPF reads that compiled projection.

Remaining tracked generation profile and product-fit verdict files are historical
test/reproduction inputs. The profile is also used by the active independent
KNOWLEDGE #44 coverage workflow; it is not an implicit current compiler input.
Stage semantic/support/model-observation and PROMPT-reference assets are frozen
research (recovery: `research/README.md`).

Ignored source/derived/runtime trees may contain irreplaceable local assets. They
remain protected in their original workspaces and are not covered by Git archive.
Git absence is not deletion permission. UserData/Library/LoRA are separate user
domains and must never be treated as generated build output.
