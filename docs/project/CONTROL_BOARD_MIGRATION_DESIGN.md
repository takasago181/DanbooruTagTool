# CONTROL BOARD MIGRATION DESIGN

Status: **HISTORICAL / NOT EXECUTED / SUPERSEDED**

This document preserves the design exploration for a GitHub Project-based management board.

Final decision: Issue #47 was closed as **NOT PLANNED** on 2026-09-10.

The project will not create or maintain the proposed GitHub Project board at this time.

## Current management model

Use only:

1. `docs/project/CURRENT_STATE.md` — global routing/current state/dependency order
2. live GitHub Issues — task contract/completion/evidence/checkpoints
3. `docs/project/CURRENT_DEV_TASK.md` — current core DEV Codex mirror

Do not treat this historical design as an instruction to create fields, views, Project items, dependencies, or a new management authority.

## Why superseded

The proposed board would duplicate information already held by CURRENT_STATE and Issues and would create another synchronization surface. The project deliberately prefers fewer management layers and lower drift risk.

## Historical value

Keep Git history for the original detailed proposal if future scale makes a board genuinely necessary. Reconsider only through a new explicit Issue based on demonstrated management pain, not because this historical design exists.
