## 2-B. 日本語辞書改善

**本体Issue: #36**  
**現在の再設計Issue: #38**

**状態: 🟢 R3設計・テスト準備中 / ⏸️ 大量処理は停止**

### 何をしている？
Generalタグや関連候補などについて、
- 画面に出す自然な日本語
- 日本語検索で使う検索語

を整備します。

### なぜ #36 と #38 に分かれている？
#36で最初の100件を試したところ、既存の日本語検索データに
- 狭すぎる訳
- 広すぎる訳
- subtype
- meme・俗語
- 関連語を同義語扱いしたもの

などが多く含まれていることが分かりました。

そのため大量処理を止め、#38で **安全に自動化するR3ルール** を作り直しています。

つまり:

`#36 日本語辞書改善本体 → 問題発見 → #38で自動化方法を再設計 → PASS後に#36を再開`

という関係です。

# 4. 支援する常設班

常設班はこの4班だけです。

### 開発班
本体仕様・実装・main統合を担当。Codexは独立班ではなく開発班の実装担当。

### 監査班
他班の成果を独立確認し、PASS / HOLD / 差し戻しを判定。

### 知識班
WAI / Illustrious / NoobAI / Anima等の画像生成知識や、Tagger能力・根拠を調査。

次の大きな仕事は、辞書freeze後のTagger coverage比較。

### Prompt班
Stage10のPrompt設計、代表ケース、A/B質問、正式handoffを担当。

現在は#5に加え、日本語辞書R3 (#38)にも知識を返しています。
